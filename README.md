# ⚡ Hassanain Abbas — Autonomous AI Agent & Automation Architect Portfolio

An ultra-modern, futuristic, robotic AI portfolio built with **Next.js 14 (App Router)**, **Tailwind CSS**, and **Framer Motion**. Designed as a high-end AI agency & SaaS product experience rather than a typical resume.

---

## 🌌 Live Architecture & Design System

- **Color Palette**:
  - `Deep Black`: `#05070A`
  - `Charcoal Glass`: `#10131A`
  - `Neon Blue Accent`: `#00D1FF`
  - `Electric Violet Accent`: `#7A5CFA`
  - `Cyber Glassmorphism`: Backdrop blur + rotating conic gradients + hover border glow
- **Typography**:
  - Headings: `Space Grotesk` (Google Font via `next/font/google`)
  - Body & Telemetry: `Inter` + `JetBrains Mono`
- **Robotic UX & Interactive Details**:
  - **Custom Glowing Neon Cursor**: Spring-physics outer ring and center precision dot with magnetic hover states.
  - **n8n Workflow Node Canvas**: Interactive 60fps HTML5 canvas simulating dynamic moving nodes and glowing connection wires that react to mouse proximity.
  - **Status Protocol Badges**: `SYSTEM ONLINE`, `AI AGENT READY // PROTOCOL v4.2`, `LATENCY: 12ms`, `UPTIME: 99.98%`.
  - **Infinite Marquee**: Seamless ticker of core tools (`n8n`, `LangChain`, `OpenAI GPT-4o`, `Pinecone`, `Playwright`, `Docker`).
  - **Case Study Modal**: Full architectural breakdowns for each production AI agent.
  - **Client Verification Testimonial Slider**: Glassmorphic cards with cryptographic execution hashes.

## 🚀 Getting Started

### 1. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Build for Production
```bash
npm run build
```
Verify compiled static routes and optimized chunks.

### 3. Start Production Server
```bash
npm run start
```

## 🌐 Deploy to Vercel in 60 Seconds (Zero Config)

1. Push this directory to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "feat: futuristic AI agent portfolio"
   git branch -M main
   git remote add origin https://github.com/HassanainAbbas/Work-portfolio.git
   git push -u origin main
   ```
2. Log in to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your repository and click **Deploy**.
4. Next.js 14 App Router is natively detected with 100% automated optimization.
